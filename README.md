# End-to-End DevSecOps CI/CD Pipeline

This project demonstrates a complete DevSecOps CI/CD pipeline using:

- Python
- Flask
- GitHub Actions
- AWS EC2 Self-Hosted Runner
- SonarCloud
- Snyk
- Docker
- Docker Hub
- Kubernetes (Minikube)
- Pytest

## Project Structure

```text
devsecops-flask-app/
├── app.py
├── requirements.txt
├── test_app.py
├── .gitignore
└── README.md
```

## Features

- REST API built with Flask
- Health check endpoint
- Unit testing with Pytest
- Ready for Docker containerization
- Ready for GitHub Actions CI/CD
- Ready for SonarCloud and Snyk integration
